# Credits

Florecer's code is released under the MIT License (see `LICENSE`). Every piece of art, music and
sound that the game ships comes from the packs below, all released under **CC0-1.0** (Creative
Commons Zero, https://creativecommons.org/publicdomain/zero/1.0/), or is the project's original
work (the last section). CC0 asks for no attribution; they are credited here anyway, with thanks.

The packs live in `assets-src/packs/` and are not committed; `npm run assets` extracts exactly the
files listed under each pack into `public/assets/` (wave files brought to mono at 22.05 kHz), and
`npm run assets:check` proves the committed copies match the zips. Each line below is
`file inside the pack` → `file under public/assets/`.

## Original work

- Author: Dayan Cabrera
- License: MIT
- Source: https://github.com/DayanCabrera2003/daa-blossom-game
- Used for: The shapes drawn by code (sprout bodies and faces, sun and moon badges, folded flowers, the faces of the Council), and the sounds and the crickets of the prologue synthesized from versioned parameters by the project's own tools.

The shapes are drawn by the game at run time. The sounds are additive bell synthesis
(`tools/synth/bell.ts`) and, for the crickets of the prologue, trains of sine pulses
(`tools/synth/crickets.ts`), from the parameters in `tools/synth/sounds.ts`: `npm run sounds` (or
`npm run assets`) writes them, mono at 22.05 kHz, and lists them in the manifest. Each line below
is `the sound's parameters` → `file under public/assets/`.

## Libraries

The game also ships the code of the libraries below, which the Codex loads only when a book is
first opened. They are not art, music or sound, so the CC0 rule of this file does not apply to
them; their licenses ask for the notices kept in their folders under `node_modules/`, and they are
credited here.

### KaTeX

- Authors: Khan Academy and the KaTeX contributors
- Version: 0.19.0
- License: MIT
- Source: https://katex.org (https://github.com/KaTeX/KaTeX)
- Used for: Typesetting the formulas of the Codex (its stylesheet included); `contrib/` is not used.

### KaTeX fonts

- Authors: Design Science, Inc. (the MathJax fonts, 2009-2010) and Khan Academy (2014-2018)
- Version: the one shipped with KaTeX 0.19.0
- License: SIL Open Font License 1.1 (https://openfontlicense.org)
- Source: https://github.com/KaTeX/katex-fonts
- Used for: The letters and symbols of the formulas of the Codex. The build copies them in woff2,
  woff and ttf, as KaTeX's stylesheet names them; browsers fetch only the woff2.

### marked

- Authors: MarkedJS and Christopher Jeffrey
- Version: 18.0.14
- License: MIT (with the BSD-style notice of John Gruber's original Markdown, kept in its license)
- Source: https://marked.js.org (https://github.com/markedjs/marked)
- Used for: Turning the Markdown of the Codex entries into pages, with the project's own extension
  for the formulas.
